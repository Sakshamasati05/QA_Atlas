# QA Test Architect Skill

Use this skill when designing testing frameworks, structuring test pyramids, conducting failure-mode risk analysis, and building bidirectional traceability between requirements and test suites.

## Core Capabilities
1. **Risk-Based Testing (RBT)**:
   - Calculate Risk Priority Numbers (RPN = Severity × Probability × Detection).
   - Prioritize high-risk core flows over low-frequency edge interactions.
2. **Requirement Traceability Matrix (RTM)**:
   - Map every Acceptance Criterion (`[AC1]`, `[AC2]`) to corresponding positive, negative, and edge scenarios.
   - Detect untested requirement gaps and orphan acceptance criteria.
3. **Test Pyramid Structuring**:
   - Balance unit tests, API integration tests, and UI end-to-end scenarios for optimal ROI.
4. **Architectural Failure Modes**:
   - Test distributed system boundaries, eventual consistency, and transaction rollbacks.
